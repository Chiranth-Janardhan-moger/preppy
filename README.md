# PREPPY - Haute Couture & Fine Atelier

A modern luxury e-commerce application for PREPPY Haute Couture & Fine Atelier, featuring curated seasonal collections, luxury catalog browsing, interactive product quick-views, wishlist management, and multi-currency pricing support.

## Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide React
- **Animations**: Lenis smooth scrolling, Motion

## Features

- **Haute Collections Catalog**: Explore bespoke gowns, luxury tuxedos, and seasonal capsules.
- **Interactive Quick View & Cart Drawer**: Seamless shopping experience with responsive modals.
- **Multi-Currency Support**: Dynamic price conversion across USD, EUR, GBP, and INR.
- **Wishlist & Personalization**: Curate personal favorite items across sessions.

## Quick Start

### Prerequisites

Node.js (v18+) and npm or bun.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/optifysupport/preppy.git
   cd preppy
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
